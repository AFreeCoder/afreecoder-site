我自己开发项目的时候，经常为怎么写 commit message 头疼。

我知道好的 commit message 应该遵循下面的规范：

```
- 遵循 Conventional Commits 规范：`<type>(<scope>): <description>`
- 类型清晰：feat、fix、docs、refactor、chore...
- 描述简洁但说明白做了什么、为什么做
```

**我知道，但我做不到。。。**

所以，我的 commit message 常常是下面这样：

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/b06c6a6b155b515d23bae0e42ceb1130c55eb3d999ca902623caf1a1f637c704.png)

鬼知道优化的是什么。。。

现在把这个活甩给 Claude Code 后，我的 commit message 长这样：

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/805ed71ba7ae4e0ce9b5aa6aaf6832fab6dae1abff6517d7624eb5bd58d82915.png)

修改类型、简介、修改范围、修改明细一应俱全，甚至还添加了协作者，**一目了然**！

整个过程，我只需要在 Claude Code 中输入如下命令：

```
/commit 
```

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/6db35c754d691c5f84bb0ba7ca550fa55a658885157643be4b67df301a28b56c.png)

是不是很简单？

# 我是如何实现的？(Claude Code + Codex)

## Claude Code 解决方案

 Claude Code 支持自定义 slash command，说人话就支持自定义斜杠命令比如 `/commit`，具体的实现方式就是在你的Claude Code 用户目录下添加一个同名 markdown 文本文件：

`~/.claude/commands/commit.md`

里面内容很简单，文字描述命令 `/commit` 允许执行的 bash 命令，参数，上下文，任务行为等。

当然，这个文件并不需要你来写，你可以对 Claude Code 说：

> 添加一个用户级的 slash command  “/commit”，功能是阅读当前本地 git 仓库的最新变更，总结，并进行 commit。参考：https://code.claude.com/docs/zh-CN/slash-commands。

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/4b082a6548f6c3a8e6d858749bf9d4a76ffc483b0bddd62658252ee5a492fcc7.png)

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/16cbdeb7815e65ca42c99514a79536150a426dc88a4ced8028a382d136b4d596.png)

Claude Code 会自动热加载 `~/.claude/commands/commit.md`，如果没出现，新开一个对话就行。

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/914ad8bb13053c4980192bf99ea6734586df403c42e696dfe987c87a1d148f0b.png)

## Codex 的解决方案

Codex 中不支持 slash command，但是可以通过最近比较火的 skills 来实现，效果一样，也很简单，直接和 Codex 说就行：

> **Skill Creator** 创建一个 git 自动提交功能，功能是阅读当前本地 git 仓库的最新变更，总结，并进行 commit。

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/86a209d0382fc5bc7c67e6757eca144665aca384b70f2d43396e2969cbd11fa1.png)

也是输入 `/` 调出 `git auto commit` 这个技能，一键触发。

就是感觉有点大材小用了。。。

# 结论

最近才开始好好研究 Claude Code 和 Codex 的一些小技巧，一点初步的感受：

- 绝大部分电脑上的工作流，都可以通过 Claude Code、Codex 这种  agent 来执行。
- markdown 是 agent 理解和执行的基础，不管是 command，还是 skills，核心都是 markdown，都是自然语言文本。
