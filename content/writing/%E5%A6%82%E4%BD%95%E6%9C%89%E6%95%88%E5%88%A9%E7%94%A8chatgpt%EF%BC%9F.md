**我的观点是：现在花精力研究如何有效利用 ChatGPT，还不如花精力研究 ChatGPT 对应的 Agent 工具——Codex（只要是 ChatGPT 会员，就可以用 Codex）。**

ChatGPT 仅仅是个聊天工具，只能给方案，给建议，不能帮你完成任务，而 Codex 是真正可以帮你操作电脑，完成任务的“**数字员工**”

下面分享几个我用 Codex 实现的自动化场景，希望能给大家一些启发。

## 1. 半小时创建网页剪裁工具

我平时看到好文章，习惯性地收藏到本地。AI 时代，文字信息存储最好的载体就是 Markdown，因此我把笔记软件换成了 Obsidian。

尝试了很多网页剪裁工具：简悦、Obsidian Web Clipper、MarkDownload... 要么太复杂，要么效果不满意。

于是我把 GitHub 上思源笔记的网页剪裁插件扔给 Codex，让它参考这个项目创建一个网页剪裁 skill：

```
[Skill Creator] 参考 GitHub 项目：https://github.com/siyuan-note/siyuan-chrome，
创建一个网页剪裁 skill，效果是给一个网址，将网页剪裁成本地 markdown（含图片）
```

几轮对话下来，半小时搞定。现在我只需要输入：

```
剪裁文章：https://mp.weixin.qq.com/s/xxx
```

Codex 就会自动：
1. 抓取网页内容和图片
2. 转换成 Markdown 格式
3. 保存到指定目录
4. 图片重命名并存放到 assets 目录

**一条命令，完成以前需要折腾半天的事情。**

## 2. 一键生成规范的 Git Commit

写 commit message 是个让很多程序员头疼的事。

我知道好的 commit 应该遵循 Conventional Commits 规范：`<type>(<scope>): <description>`

**我知道，但我做不到。**

所以我的 commit message 经常是「优化」「修复」「更新」这种鬼才看得懂的东西。

现在，我用 Codex 创建了一个自动分析总结变更记录的 skills，只需：

```
/commit
```

它会自动：
1. 读取 git 仓库的所有变更
2. 分析修改内容
3. 生成规范的 commit message
4. 执行提交

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/6db35c754d691c5f84bb0ba7ca550fa55a658885157643be4b67df301a28b56c.png)

修改类型、简介、修改范围、修改明细一应俱全，甚至还会添加协作者。

**以前纠结半天的事，现在一条命令搞定。**

## 3. 自动归档项目看板并生成新一周计划

我用 Obsidian 做项目管理，每周一需要复盘上周进展、归档看板、生成新一周计划。

这个流程虽然不复杂，但每周都要手动操作，很容易忘记或者敷衍了事。

于是我让 Claude Code 创建了一个 `dashboard-renew` skill：

```
/dashboard-renew
```

它会自动：
1. 检查当前 Dashboard 状态
2. 归档上周内容到历史文件
3. 分析历史数据，诊断问题
4. 生成新一周的 Dashboard 模板

![](https://tjjsjwhj-blog.oss-cn-beijing.aliyuncs.com/article-publish-assistant/5112ff8bceafe06dab163280c57fac1de2ac39693df6403c0059b565895cd929.png)

**重复性的管理工作，都交给 AI 来做，我只负责思考和决策。**

## 为什么  Codex 比 ChatGPT 对话更有效？

1. **减少沟通成本**：不用反复描述上下文，Agent 直接读取你的文件和项目
2. **可复用**：创建一次 skill，之后一条命令触发
3. **可组合**：多个 skill 可以串联，形成复杂的自动化流程
4. **真正落地**：不是给你一段代码让你自己跑，而是直接帮你执行完

## 结尾

所以，别研究 ChatGPT 怎么用了，研究 Codex 吧。真正高效利用 AI 的方式，是把 AI 变成你的数字员工，让它直接操作你的电脑，帮你完成工作。

**这就是 Agent 的意义。**

Codex 是 ChatGPT Plus 用户可以直接使用的 Agent 工具，类似 Claude Code 是 Claude 的对应的 Agent 工具，同样能实现上面的功能。
